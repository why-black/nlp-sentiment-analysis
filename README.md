# NLP Sentiment Analysis & Data Audit (DS1_Tweets)

Реализация и исследование пайплайна обработки естественного языка (NLP) для классификации тональности твитов (positive, negative, neutral). В банковской сфере подобные модели используются для автоматизации анализа клиентских обращений и отзывов. 
Цель проекта — освоить методы векторизации текста и научиться проводить независимую валидацию ML-моделей, выявлять дефекты данных (Data Leakage) и работать с сильным дисбалансом классов.


## Реализованные архитектуры и пайплайны

1. **Text Preprocessing (Очистка и нормализация):**
   - Реализованы методы токенизации, стемминга (`PorterStemmer`) и лемматизации (`WordNetLemmatizer`).
   - Удаление стоп-слов и исправление опечаток с помощью `SpellChecker` (с кешированием через `lru_cache` для оптимизации скорости).
   - Написание кастомных регулярных выражений для очистки артефактов исходного датасета.
2. **Feature Engineering (Векторизация текста):**
   - Сравнение подходов Bag of Words (`CountVectorizer`) и TF-IDF (`TfidfVectorizer`).
   - Использование символьных и словесных N-грамм.
   - Обучение собственных эмбеддингов через **Word2Vec** (`Gensim`).
3. **Машинное обучение (Классификаторы):**
   - Baseline: `LogisticRegression` (с подбором `class_weight`).
   - Альтернативы: `LinearSVC`, `SGDClassifier`.
   - Подбор гиперпараметров через `GridSearchCV` и кросс-валидацию `StratifiedKFold`.


## Методология оценки (Validation)
Поскольку в исходных данных присутствовал скрытый шум и дисбаланс классов, применялись следующие подходы к валидации:
- **Аудит данных (Data Leakage):** Обнаружены скрытые маркеры (`happy`, `unhappy`) внутри текстов. Показано, что удаление этих маркеров снижает Accuracy с 91% до честных 87%, но делает модель робастной.
- **Работа с дисбалансом:** Анализ `classification_report` (упор на F1-score macro и Precision/Recall), а не только на общую Accuracy.
- **Поиск аномалий:** Использование `cosine_similarity` для поиска топ-10 наиболее похожих пар твитов (валидация на дубликаты и шаблонный спам).


## Стек
Python, Pandas, NumPy, Scikit-learn (LogReg, LinearSVC, GridSearchCV), SciPy (sparse matrices), NLTK, Gensim (Word2Vec), SpellChecker, Regex.
